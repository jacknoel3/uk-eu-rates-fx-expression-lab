# Notebooks

Notebooks are for exploration, diagnostics and presentation. Production calculations belong in `src/`, and important logic may not exist only in a notebook.

Notebooks should use project modules and saved configuration, and names should reflect stage and purpose.

| Folder | Purpose |
|---|---|
| `01_data_audit/` | Inspect source definitions, coverage, timestamps, missingness and feasibility |
| `02_instrument_validation/` | Reconcile instrument construction, signs, units and toy scenarios |
| `03_signal_research/` | Explore transparent signals and benchmarks using approved returns |
| `04_results/` | Present frozen or reviewed outputs generated from saved configurations |
