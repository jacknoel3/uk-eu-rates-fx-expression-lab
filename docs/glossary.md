# Glossary

Definitions are drawn from the supplied project bible and tradable-assets document. Concise clarifications are included only where they follow directly from those sources.

| Term | Definition |
|---|---|
| Policy divergence | A relative change in expected UK monetary policy versus euro-area monetary policy. |
| Positive signal | UK becoming more hawkish, or less dovish, relative to the euro area. |
| Long GBP | Exposure that gains when sterling strengthens; under EUR/GBP this generally corresponds to a fall in the quoted price. |
| Carry | Return component associated with interest-rate differentials or holding/rolling an instrument through time. |
| DV01 | Approximate currency value change for a one-basis-point yield move. |
| DV01-neutral | Leg quantities selected so first-order rate sensitivity is balanced across paired positions. |
| Duration | Interest-rate sensitivity used to approximate how bond prices respond to yield changes. |
| Synthetic return | Modelled return derived from curves or theoretical prices rather than a directly observed traded total-return series. |
| Proxy return | Approximate P&L or return used as a diagnostic or fallback, not a directly tradable return. |
| Event response | Asset movement measured in or around a monetary-policy announcement window. |
| Post-event return | Return measured after the event window and after a documented execution lag. |
| Volatility targeting | Scaling positions to a common ex-ante volatility basis using lagged risk estimates, floors and caps. |
| Holdout | Final sample segment locked before full performance exploration and opened only after methodology freeze. |
| Methodology freeze | End-of-Week-5 freeze of signals, primary comparisons, costs and robustness plan; later changes are limited to bug fixes and pre-agreed tests. |
| Cleanest expression | Best balanced exposure to the intended view after sensitivity, contamination, risk, costs, regimes and interpretability are considered. |
| Steepener | Curve position that benefits when the gap between long-term and short-term yields increases. |
| Flattener | Curve position that benefits when the gap between long-term and short-term yields decreases. |
| Spot return | Return from change in the spot FX price. |
| FX excess return | FX return concept that includes funded currency exposure rather than only spot appreciation. |
| Carry and roll-down | Return components from holding an instrument through time and from movement along the curve, distinct from pure price movement due to yield changes. |
| Observed tradable return | Return from a directly observed futures, total-return or other tradable instrument series. |
| Approximate proxy | Diagnostic approximation that must not be described as an observed market trade. |
