# Data

Raw data is immutable. Once ingested, raw files should not be manually edited.

Raw licensed or confidential data must not be committed publicly without permission. Interim data contains reproducible intermediate transformations. Processed data contains analysis-ready outputs derived from documented code and configuration.

Every data snapshot should include metadata covering source, identifier, retrieval date, timestamp convention, licence, known caveats and transformation history. No data file should be manually edited after ingestion.
